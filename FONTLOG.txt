FONTLOG for Zad
================

Zad is a renamed, lightweight web build derived from IBM Plex Sans Arabic
(SIL Open Font License 1.1). It keeps Arabic joining, ligatures, and
mark positioning intact, ships five static weights for the web (woff2 +
ttf), and does not use IBM's Reserved Font Name "Plex".

Maintainer of this derivative: Ahmed Morsy (GitHub @ahmedvnabil).
Upstream designers: Mike Abbink, Paul van der Laan, Pieter van Rosmalen,
Wael Morcos, Khajak Apelian (Bold Monday / IBM Corp.).

ChangeLog
---------

3. 2026-10-21 — Metadata accuracy + build hygiene
   - Documented Zad honestly as an OFL derivative of IBM Plex Sans Arabic
     (5 weights 300–700), not an original foundry design.
   - build.py: normalised family underlineThickness/Position; stopped
     writing Macintosh name records (matching upstream).
   - build.py: added TrueType smart dropout control to 'prep'
     (FontBakery smart_dropout); outlines, metrics and HarfBuzz shaping
     verified identical to the previous build.
   - FontBakery 1.1.0 universal, 5 weights: 0 FATAL, 10 FAIL, 30 WARN,
     360 PASS (was 15 FAIL). Remaining FAILs (arabic_spacing_symbols,
     case_mapping) and all WARNs are inherited from IBM Plex Sans Arabic
     and need design changes to fix.
   - Added MCP server docs for AI-agent install/preview/generation tools.

2. 2026-06-14 — Five-weight web kit
   Expanded the shipped ladder to Light 300, Regular 400, Medium 500,
   SemiBold 600, Bold 700. Reproducible build from `_src/` via build.py.
   FontBakery universal run recorded in qa.json.

1. 2026-06-12 — Initial public release
   First public Zad kit: renamed/subset derivative of IBM Plex Sans
   Arabic under SIL OFL 1.1. Arabic + Latin coverage.
